    0.6 常见动摇与自查(FAQ)

    Q1:要不要先学 C / Python / Java 打底,再学 C++?
    不用。指针、内存、对象模型这些"难的部分"换任何语言都躲不掉,晚学不如早学;第一门语言期不同时开第二门,避免互相干扰。

    Q2:数学底子差,这条路走得通吗?
    走得通,但③必须"立即并行"而不是"等有空补"。数学按月计,不按周计:线代先行(3Blue1Brown 两天就能建立直觉),高数跟课内进度。

    Q3:视频倍速刷完一遍,算学过吗?
    不算。唯一判定:合上视频,能否不查资料做出该段的「过关标准」。视频是输入,过关标准才是验收。

    Q4:卡了很久,是不是我不适合学 CS?
    不是。指针、虚函数、DP、虚拟内存……人人卡。动作见 §1「卡壳急救包」:缩小问题、画图、换讲法、切轨道。卡住是知识分层的信号,不是智商的信号。

    Q5:课内 GPA 和这套清单冲突吗?
    高度重叠——数据结构、计组、OS、计网、数学三门就是专业课本身。按清单学 = 课内拿分 + 课外深挖,不是两份工。考试周课内优先,清单停两周不塌。

    Q6:要不要报班 / 买付费课?
    先把免费主资源跑完一轮再说。真正值得花钱的只有:好书、真题、一台能跑 Linux 的电脑。"付费 = 买了安全感"不等于学了。

    Q7:AI 都这么强了,还有必要按部就班打基础吗?
    更有必要。AI 产出的是"平均答案",判断它对不对、敢不敢用,靠的恰是你自己的底座;底座越深,杠杆越大。用法与红线见附录B。

    Q8:清单这么长,做不完怎么办?
    它是地图,不是死线。走完 ①②③④⑤ 底座 + ⑧ 选定主修,本指南就完成使命;⑥⑦⑨⑩ 是沿途自然产出。宁可慢,不可跳。

    ① 蒙特卡洛估计 π(概率论):

    import numpy as np
n = 1_000_000
x, y = np.random.rand(2, n)
inside = np.mean(x**2 + y**2 <= 1)

    ② 十行梯度下降拟合直线(高数 + 线代合体,AI 的数学缩影):

    import numpy as np
x = np.linspace(0, 1, 50)
y = 2.0 * x + 1 + np.random.randn(50) * 0.1   # 真值 w=2, b=1 加噪声
w, b, lr = 0.0, 0.0, 0.1
for _ in range(200):
    grad_w = np.mean((w * x + b - y) * x)     # 均方误差对 w 的偏导
    grad_b = np.mean(w * x + b - y)           # 对 b 的偏导
    w, b = w - lr * grad_w, b - lr * grad_b
print(w, b)                                    # 逼近 2 与 1

    ③ 图片 SVD 压缩(线代):

    import numpy as np
from PIL import Image                      # pip install pillow
img = np.asarray(Image.open("pic.png").convert("L"), dtype=float)
U, S, Vt = np.linalg.svd(img)
for k in (5, 20, 50, 200):                 # 只保留前 k 个奇异值
    lowrank = (U[:, :k] * S[:k]) @ Vt[:k]
    Image.fromarray(lowrank.clip(0, 255).astype(np.uint8)).save(f"k{k}.png")
# 对比四张图:多小的 k 还能认出原图?k 与压缩率/画质怎么权衡?

    APPENDIX A — LEARNING METHOD

    • 费曼检查:学完任何主题,花 5 分钟假装讲给高中生听;讲不下去的地方就是没懂的地方,回去只补那一块
    • 主动回忆 > 重读:合上资料先默写再翻书。重读产生的"熟悉感"是学习里最大的错觉
    • 间隔重复:错题、生词、概念卡按 3 / 7 / 21 天重做(②的错题本、⑦的生词卡都是这个原理);工具用 Anki 或纸卡皆可
    • 最小可复现:任何 bug 或概念,缩到 30 行内复现;复现的一半功夫会在过程中直接变成理解
    • 笔记原则:只记"自己的话 + 踩过的坑",不抄书;笔记是写给三个月后忘光的自己看的
    • 节奏管理:主线不超过 3 条(§0.3);每个学习单元以"完成一个可验证的小产出"收尾,而不是"看了 X 页"

    APPENDIX B — AI TEAMMATE MANUAL

    绿灯(放开用):

    • 同一个概念让它换三四种讲法,直到你懂;让它举"你专业里的例子"
    • 让它当苏格拉底:"只追问、别给答案,直到我自己说出来"
    • 让它 review 你的代码、出题考你、生成练习数据、翻译文档、改 README 表述

    黄灯(有条件用):

    • 看不懂报错 → 让它"解释这个错误在说什么",自己改;卡壳超 30 分钟 → 只要提示不要完整解法
    • 要了完整解法 → 必须合上重写一遍,写不出来 = 还没学会

    红线(别做):

    • 让它替你写作业或项目核心代码——你的手是唯一的验收器,AI 代写的学习值为零
    • 未经批判全盘接受——大模型会一本正经地胡说,API 用法、复杂度、考研政策等关键事实,回 cppreference / 官方文档 / 研招网核对
    • 把 API key、密码、个人隐私喂给任何在线 AI
