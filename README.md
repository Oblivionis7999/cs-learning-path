# CS·PATH — 计算机科学完整学习路径

> 目标考研深造 · 复合型 · 抗替代 · 可长期进化 · C++ 首发

**在线阅读:** <https://oblivionis7999.github.io/cs-learning-path/>

![preview](docs/preview.png)

一份**可打勾**的计算机科学自学路径,覆盖从零基础到考研深造的完整底座:10 条轨道 + 4 篇附录,共 **258 个可勾选任务项**。

## ✦ 特性

- **10 条轨道**:C++(启动项)→ 数据结构与算法 → 数学三门 → 系统三课(计组/OS/计网)→ Linux + Git → Python 速通 → 英语 → 六选一专精方向(具身智能 / AI Infra / AI×行业 / 网络安全 / 量化 / 图形学)→ 考研应试回收 → 项目阶梯
- **没有时间表**:只规定先后顺序与依赖关系,速度由自己的节奏决定;每段有「过关标准」当验收线、「坑」提前排雷
- **258 项进度打勾**:勾选状态自动保存在浏览器本地(localStorage),刷新、关机都不丢
- **带血肉的内容**:卡壳急救包、错题本模板、三个可运行的数学实验代码骨架、LLM API 调用骨架、README/简历模板、六个专精方向的出口与适合信号、考研全流程地图
- **四篇附录**:自学方法论 / AI 队友使用手册(绿灯·黄灯·红线)/ 环境软件清单 / 认知防坑清单
- **单文件网页**:零依赖、离线可用,双击 `index.html` 即可;桌面 / 移动端自适应

## ✦ 使用

| 方式 | 说明 |
|---|---|
| 在线版 | 直接访问上方链接 |
| 本地版 | 下载 `index.html`,双击打开 |
| 进度 | 打勾即存,数据只在本机浏览器,不上传任何服务器 |

不知道"现在该干嘛"时:回 §0 查依赖图与并行策略;卡住时查 §1 的「卡壳急救包」。

## ✦ 本地构建

网页由仓库根目录的 Markdown 源文档生成:

```bash
python src/build_site.py   # 无第三方依赖,纯 Python 标准库
# 读取 ./计科学习路径_完整版.md + ./src/site_template.html → 生成 ./index.html
```

## ✦ 目录结构

```
├── index.html              # 成品网页(GitHub Pages 入口)
├── 计科学习路径_完整版.md    # 内容源文档(唯一事实来源)
├── docs/preview.png        # 预览图
└── src/
    ├── build_site.py       # Markdown → HTML 构建脚本(纯标准库)
    └── site_template.html  # 样式与交互模板
```

## ✦ 说明

- 主线学习资源几乎全部免费(learncpp、CSAPP labs、MOOC、OSTEP 等),完整清单见网页末尾「资源总索引」
- 资源随时间会更新,主资源失效时按同定位替换即可,不影响路径结构
- 进度数据仅存于本机浏览器;清除浏览器数据会重置进度
